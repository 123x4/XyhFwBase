# Hall 四字节移位图

图中的每个格子代表 8 位。两个 16 位移位寄存器按从 MCU 的 MOSI 到 MISO 的顺序展开。每个 SCLK 短脉冲移 1 位，表格每 8 个时钟拍一张快照。每颗芯片的两个格子是逻辑高、低字节位置。

```text
                       H1 左键                   H2 右键
MOSI  ──────→   [ 低8位 │ 高8位 ]  ──→   [ 低8位 │ 高8位 ]  ──────→  MISO
                 入口                                  出口
```

## 第一轮把请求推入芯片

```text
发出的字节          H1 左键                  H2 右键
                 [ 低8 │ 高8 ]           [ 低8 │ 高8 ]
 tx[0] →         [ T0  │  ·  ]    ──→    [  ·  │  ·  ]
 tx[1] →         [ T1  │ T0  ]    ──→    [  ·  │  ·  ]
 tx[2] →         [ T2  │ T1  ]    ──→    [ T0  │  ·  ]
 tx[3] →         [ T3  │ T2  ]    ──→    [ T1  │ T0  ]
```

T0–T3 对应 tx[0]–tx[3]，点表示原来留在链里的字节。按各芯片的高字节、低字节顺序读，右键收到 [T0][T1]，左键收到 [T2][T3]。第一轮同时把原内容移入 rx[]，第二轮会覆盖它。

## 长脉冲后把回读帧移出

Lh/Ll 是左键回读帧的高/低字节，Rh/Rl 是右键回读帧的高/低字节。中间的 SCLK 长脉冲和低电平等待让每颗芯片按各自收到的地址准备回读帧。

```text
第二轮 MOSI        H1 左键             H2 右键              MISO → RAM
                 [ 低8 │ 高8 ]      [ 低8 │ 高8 ]
开始前           [ Ll  │ Lh  ] ──→ [ Rl  │ Rh  ]
 tx[0] →         [ T0  │ Ll  ] ──→ [ Lh  │ Rl  ] ─────→ Rh → rx[0]
 tx[1] →         [ T1  │ T0  ] ──→ [ Ll  │ Lh  ] ─────→ Rl → rx[1]
 tx[2] →         [ T2  │ T1  ] ──→ [ T0  │ Ll  ] ─────→ Lh → rx[2]
 tx[3] →         [ T3  │ T2  ] ──→ [ T1  │ T0  ] ─────→ Ll → rx[3]
```

每行的输出字节是该行 8 个时钟期间移出的数据。SSP1 每 8 位形成一个接收字节，CPU 读 DR 写入对应的 rx[i]。H5 普通寄存器读回的低 8 位有效，所以代码使用 rx[1] 和 rx[3]。第二轮结束后，两颗芯片的移位链里又是发送缓冲的四个字节。
