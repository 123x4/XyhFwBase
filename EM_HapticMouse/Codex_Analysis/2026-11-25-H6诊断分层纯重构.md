# H6 诊断分层纯重构

已将 H6 诊断拆成校频 `H6_Calibrate()`、传输 `H6_ReadReg()` 和 `H6_WriteReg()`、一次性场景与 `H6_Report()`。校频和寄存器时间常量集中为 126/60 µs 和 37/4 µs。校频仍至少 16 次、最多 128 次，回读窗口 0x7C–0x84，成功的事务之后等待 20 ms。每秒报告保留旧 `[I]Hall_H6_Diagnostic:` 前缀、全部字段和 CRLF，`H6_CAL` 仍放最后。 [代码](../app/button.c#L987)

| Keil C/C++ Define | 执行内容 |
| --- | --- |
| 默认或 `H6_DIAG_STAGE=2` | 校频、0x35 三读、0x07 写入/读回/恢复/再读 |
| `H6_DIAG_STAGE=1` | 校频、0x35 三读 |
| `H6_DIAG_STAGE=0` | 校频 |

## 验证

1. Clang 预处理比较通过。Lina H5 PWM、IRPT_V4 和 V4_HALL_HPTIC_V4 的输出与改前一致（忽略空白）。31 拍 NOP、PRIMASK、时钟函数以及 `Hall_H6_WriteHeader()` 的源码均逐字节核对。
2. 默认档与写测试档在模拟中的总线字节、脉冲参数、等候、USB 调用顺序及日志与原版逐字节一致。覆盖第 16 次成功、延至第 19 次成功和第 128 次失败。三个档位已编译并验证各自的事务范围。ARMCC build 960 重建和上板后四行日志逐字核对还需 Windows 台架完成。
