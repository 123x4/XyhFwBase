# GTRY164 配置讲解（摘要版）

配合 [交互式讲解页](2026-11-25-H6配置讲解.html) 使用。完整版每项都带位定义、页码、H5 对应、XENO 值和写错后果。

## 1. 一句话理解

把 H6 看成“磁铁距离 → 数字”的流水线，配置就是调每一站的旋钮：

| 站 | 管什么 | 我们动不动 |
| --- | --- | --- |
| ① 模拟前端 | LNA（粗）+ PGA（细） | 动，见 0x0B/0x09/0x29/0x2A |
| ② 采样节拍 | 多久测一次 | 动，124 µs |
| ③ 按键判定 | 按下变大还是变小、阈值 | 动方向（0x32），阈值不用 |
| ④ 基线 | 芯片要不要自己跟踪“没按”位置 | 不动，保持关闭 |
| ⑤ 输出杂项 | MISO 驱动、LED、固定值 | 只动 0x0C |

## 2. 两个最关键的事实

1. **`0x0C` 是唯一“默认就错”的寄存器**：默认 0xAA，手册要求 0x83。漏写 = 芯片在未定义状态工作。
2. **其余固定值默认就正确**：0x26=0x0A、0x27=0x05、0x28=0x04、0x2F=0x14、0x34=0x03、0x35=0x27，写与不写等价。

## 3. 最终写入清单（9 项）

| # | 地址 | 值 | 为什么 |
| ---: | --- | ---: | --- |
| 1 | 0x0C | 0x83 | 固定值，默认 0xAA 是错的 |
| 2 | 0x09 | 0x20 | bit5=1 才让 0x0B 的 0x8 表示 24×；低 4 位 0 → LED 电流 0 |
| 3 | 0x0B | 0x88 | LNA 24× + PGA 22.8× |
| 4 | 0x29 | 0x60 | 24× 的 LNA trim，必须随 0x0B |
| 5 | 0x2A | 0x28 | 24× 的 LNA trim，必须随 0x0B |
| 6 | 0x0F | 0x1F | 间隔低 8 位 = 31 |
| 7 | 0x10 | 0x20 | 高 4 位 = 0，[7:4] 固定 2 → 31×4 = 124 µs |
| 8 | 0x32 | 0x01 | 按下数值变小；SPS 关；[3:0] 固定 1 |
| 9 | 0x33 | 0x80 | **最后写**：连续转换开，硬件 baseline 关 |

顺序不能乱：0x33 一开，芯片就按当前参数开始连续转换，之后再写就是“边跑边改”。

## 4. H5 → H6：按功能映射

| 功能 | H5 | H6 | 差异 |
| --- | --- | --- | --- |
| 采样间隔 | 0x0A=0x0B（124 µs） | 0x0F=0x1F、0x10=0x20（124 µs） | H5 是 值×4+80，H6 是 值×4 |
| 连续转换 | 0x18 bit2 | 0x33 bit7 | 独立成寄存器 |
| 放大倍数 | 0x14=0x35(64×)、0x16=0x04(18×) | 0x0B + 0x09 bit5 + 0x29/0x2A | H6 无 64× 档，换档要改四个 |
| 固定值 | 8 个地址 | 只有 0x0C 要写 | H6 大部分做进默认值 |
| SDO 驱动 | 0x1F=0x07（12 mA） | 0x35 默认 0x27（12 mA） | 一致 |
| 滤波 / 温度补偿 | 0x13 / 0x27 | **无对应** | H6 内部处理 |
| SPS / LED | 0x0E–0x10、0x18、0x19–0x1E | 0x11/0x12/0x32 bit4、0x05–0x09 | Lina 都不用 |

## 5. 四个决策

| 决策 | 推荐 | 会让我改主意的实测 |
| --- | --- | --- |
| 硬件 baseline（0x33 bit2） | 关（0x80） | 归零位随温度明显漂移、软件基线跟不上 |
| 采样间隔 | 124 µs | 1 kHz 读取时相邻样本差异异常大 |
| 增益起点 | 0x88（24×/22.8×） | 按下/松开差值 < 3000 → 升 0x99（48×/24×）；接近 16383 或 0x3FFF → 降 16× |
| XENO 的 8 个未公开寄存器 | 第一轮不写 | 噪声大、零点偏、左右不对称，且排除机械/供电因素 |

## 6. 写后读回

| 寄存器 | 期望 | 证明 |
| --- | ---: | --- |
| 0x0C | 0x83 | 写路径生效（默认 0xAA） |
| 0x09 | 0x20 | LNA 选择位与 LED 关断 |
| 0x0B | 0x88 | 增益档 |
| 0x29/0x2A | 0x60/0x28 | trim 同步 |
| 0x0F/0x10 | 0x1F/0x20 | 间隔 |
| 0x32 | 0x01 | 极性（默认 0x41） |
| 0x33 | 0x80 | 连续转换已开 |

## 7. 五个最常见错误

1. 漏写 0x0C（停在 0xAA）→ 噪声/数值异常，难定位；
2. 选 24× 却漏 0x09 bit5 → 实际 16×，增益怎么调都偏小；
3. 只改 0x0B 不改 0x29/0x2A → 线性度变差；
4. 提前写 0x33 → 后续配置在转换中被写入；
5. 把 H5 的值抄到 H6 同名地址（0x13/0x16/0x18 等）→ 含义完全不同。
