# H6 配置定版与探针清理

台架版完成 32 项配置双芯片读回，结果为 `H6_CFG n=32 miss=0`、`H6_CAL PASS n=3`。64 条寄存器命令的高脉宽为 39.16–39.17 µs。后续原始采样探针测得 td1 约 5.04 µs，714/714 帧 CRC 通过。数据来自本轮台架回报。等按键装配后再采集按压方向和行程跨度。 [配置台架步骤](2026-11-25-H6初始化32项与读回.md) · [采样探针记录](2026-11-25-H6原始采样与CRC.md)

清理保留 32 项地址、值和顺序。校频通过后等待 20 ms，写入 32 项，再等 1 ms。USB 就绪后打印一次 `H6_CAL`，继续 USB 和入 Boot 轮询。校频失败仍会等待 20 ms，报告一次失败并跳过写入。配置表注释注明手册页码、选值原因及错误后果。XENO 有八个地址未出现在公开表里，注释保留了出处并标明位义未知。 [配置表](../app/button.c#L1003) · [启动流程](../app/button.c#L1115)

## 清理后的复测预期

| 检查 | 预期 |
| --- | --- |
| 冷启动 USB 日志 | 校频成功时仅一条 `H6_CAL PASS ...`。上位机可使用 `python .\tools\h6_usb_log.py --once`。 |
| td10 | 约 128 µs。手册窗 121.6–134.4 µs，冷启动条数随校频收敛次数变化。 |
| td6 | 校频成功后保留 **32 条约 39 µs 的写命令**。每条前面有一组 32 个短时钟。相比验证版撤掉 32 条读回命令。 |
| td1 | 清理后观察不到此前周期性的约 5 µs 采样脉冲。 |
