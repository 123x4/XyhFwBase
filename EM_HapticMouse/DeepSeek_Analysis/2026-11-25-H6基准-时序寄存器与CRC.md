## 2. 事务结构（两芯片串联时每段都是 2×16 位 = 32 个时钟）

| 事务 | 步骤 |
| --- | --- |
| 采样 HAL_CONVERT | td1 高脉冲 → td2 低等待 → 32 clocks 读回；每帧 16 位，高 2 位 CRC1/CRC0 + 14 位数据 |
| 读寄存器 | 32 clocks 装读请求（bit15=0，bit14=0，bit13:8=地址，bit7:0=任意）→ td6 高脉冲 → td5 低等待 → 32 clocks 读回（低 8 位有效） |
| 写寄存器 | 32 clocks 装写帧（bit15=1，bit14=CRC_WR，bit13:8=地址，bit7:0=数据）→ td6 高脉冲 → td5 低等待（无读回） |
| 频率校准 | td10 高脉冲 → td12 低等待 → 32 clocks 读回；两颗低字节都要落在 0x7C–0x84，否则最多重试 128 次，通过后等 20 ms |
| 软复位 | td11 高脉冲 → td9 低等待，之后必须重新初始化 |

`SSP1` 现配置 `CR0=0x0287`（CPOL=0/CPHA=1，mode 1，8 位）、`CPSR=8`、`SCR=2`，48 MHz 下为 2 MHz，符合 H6 的 1–25 MHz。上升沿输出、下降沿采样与 H6 一致。

## 3. 帧格式与 CRC

- 写帧：`bit15=1`，`bit14=CRC_WR`，`bits13:8=addr(6 位)`，`bits7:0=data`。
  **`CRC_WR = A5^A4^A3^A2^A1^A0^D7^…^D0`**（含地址）。现有 `bit_crc_write_reg[256]` 只异或数据位，直接使用会被判无效帧。
- 读帧：`bit15=0`，`bit14=0`，地址只取低 6 位（`addr & 0x3F`）。
- 采样帧：`CRC1 = D1^D3^D5^D7^D9^D11^D13`，`CRC0 = D0^D2^D4^D6^D8^D10^D12`，与 H5 完全一致，现有 `bit_error[]` 校验可继续用；`0xC000`、`0x3FFF` 会被判成 CRC 错。
- 串联移位的字节顺序（沿用 H5 已验证结论）：`tx[0..1]` 送到 H2（右），`tx[2..3]` 送到 H1（左）；回读 `rx[0..1]`=右、`rx[2..3]`=左。

## 5. 增益与 LNA 联动

- 手册：`0x0B[7:4]` 选 LNA（0x8/0x9/0xA 配合 `0x09[5]`），`[3:0]` 选 PGA（0x5=19.2× 典型，0x8=22.8×）。
- 手册联动值：16×→0x29=0x50/0x2A=0x20；24×→0x60/0x28；48×→0xA0/0x40；96×→0xF0/0x60。
- XENO：16×→0x4E/0x32；24×→0x60/0x28；上电默认 `0x88`（LNA 0x8 + PGA 0x8），配合 `0x09=0x25`。
- Lina H5 原为 64× LNA + 18× PGA（0x14=0x35、0x16=0x04），H6 没有 64× 档，需按原始值幅度与饱和情况上板重选，不能照抄。

## 6. 手册未公开但 XENO 使用的寄存器

`0x13=0x7F`、`0x15=0x05`、`0x16=0x02`、`0x18=0x03`、`0x1C=0xFF`、`0x1E=0x80`、`0x20=0x80`、`0x25=0x29`（另有低功耗组合值）。偏移校准用 `0x36/0x37/0x3B`。这些不进首版配置表，等公开寄存器路径跑通后再单独评估，并需要向芯片方确认版本适用性。
