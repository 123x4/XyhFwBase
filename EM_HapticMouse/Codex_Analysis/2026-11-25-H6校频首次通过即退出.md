# H6 校频首次通过即退出

Lina 校频循环已对齐 XENO 的退出和等待方式。每次发一条校频命令并读回两颗 H6。两颗的低字节同时在 0x7C–0x84 时立即退出，最多尝试 128 次。成功或耗尽次数后都执行一次 20 ms 等待，再进入 H6_CAL 日志和 USB／入 Boot 轮询。校频脉冲仍使用 126U/60U、31 拍 NOP 和原 PRIMASK 段。 [Lina 代码](../app/button.c#L987) · [XENO 校频](../Materials/GT_SS_XENO_APP_20260916/src/h6/h6_hal.c#L1051)

本地 Clang 模拟覆盖第 1、3、128 次成功和 128 次均失败，验证两颗回读条件、日志状态以及进入 USB 循环前恰好一次 20 ms 等待。Lina H5 PWM、IRPT_V4 和 V4_HALL_HPTIC_V4 的预处理输出均与改前一致。 [新版 Windows 测试包](Lina-H6-校频诊断-Windows.zip)

ARMCC 整体构建与台架复验待进行。冷启动若在第 2–4 次收敛，Saleae 会抓到对应数量的约 128.00 µs 脉冲，日志应为 `H6_CAL PASS n=2` 到 `n=4`。次数反映实际收敛，可以在第 1 次成功或晚于第 4 次。SCK 在最后一次回读后保持空闲，20 ms 等待在本地调用顺序中已验证。
