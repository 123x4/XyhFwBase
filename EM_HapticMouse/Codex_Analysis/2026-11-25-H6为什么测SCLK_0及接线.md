# H6 为什么测 SCLK_0，怎么接线

Lina 的两颗 H6 共用 SCLK_0。校频时，MCU 先把这根线拉高约 128 µs，通知 H6 执行校频。拉低后等待 H6 准备回读，再发短时钟移出结果。H5 实测的校频高脉冲约 128 µs，低等待只有 6.625–8.8875 µs。H6 手册要求低等待大于 50 µs，因此这一步要确认新固件实际在芯片侧留够了时间。 [H5 实测](2026-11-24-SCLK实测结果.md) · [H6 手册图 9](../Materials/GTRY164%20Magnetic%20Keyboard%20Sensor%20and%20LED%20Driver_V1.9_20261008%20%28Gtech%29.pdf#page=10) · [H6 手册 §7.8](../Materials/GTRY164%20Magnetic%20Keyboard%20Sensor%20and%20LED%20Driver_V1.9_20261008%20%28Gtech%29.pdf#page=12)

1. 烧录启用了 `GT_LINA_T1A_H6_PWM` 的诊断固件后，先拔板子 USB。分析仪 GND 接板上 GND，CH1 接之前测过的 `SCLK_0` 焊点。它与 H1 或 H2 的第 3 脚同网，CH15 空着。
2. Saleae 只启用 CH1，用 **1.8–3.6 V** 档、**80 MS/s**、**1 秒**，设高脉宽触发 **80–200 µs**。先点 Start，再插 USB。诊断版通过时可能只发一次校频命令。
3. 放大一条长高脉冲，用游标量长脉冲的上升沿到下降沿，合格范围 **121.6–134.4 µs**。再量同一个下降沿到第一枚短时钟的上升沿，必须 **大于 50 µs**，本版目标约 60 µs。后面应有 **32 个短时钟**，对应两颗 H6 各 16 位，按短时钟上升沿计数，不计长命令。
4. 导出包含完整长脉冲、低等待及后续短时钟的 CSV，并保存一行 USB `H6_CAL`。波形验证 MCU 发送的时序，USB 日志验证芯片返回值。两颗芯片的回读低字节都落在 `0x7C–0x84` 才算校频通过。 [回读判据](2026-11-24-Lina-H6校频诊断与USB日志.md)
