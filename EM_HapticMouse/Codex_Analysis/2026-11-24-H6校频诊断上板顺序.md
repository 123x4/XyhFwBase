# H6 校频诊断上板顺序

已核对 Windows 测试包中的工程、板型配置、校频代码和 USB 日志工具与当前工作区一致。当前测试包已启用 H6。

1. 下载最新版 [Windows 测试包](Lina-H6-校频诊断-Windows.zip)。在 Windows 解压后打开 `inc/my_board.h`，确认选择列表中的 Lina 两行如下：

   ```c
   //#define GT_LINA_T1A_H5_PWM
   #define GT_LINA_T1A_H6_PWM
   ```

   只改选择列表这两行。下面 H6 分支内部的 H5 别名继续用于复用引脚和 SSP1。

2. 打开包里的 `Sample.uvproj`，在 Keil 用 ARMCC build 960 重建 `Target 1`。本步的通过条件是 Build Output 显示 `0 Error(s)`，且 `output\Sample.hex` 的修改时间是这次重建的时间。请回传版本行和错误、警告摘要。若有错误，附第一条完整报错。
3. 编译通过后，按现有应用烧录方式写入 H6 板，保留 Bootloader。运行包内日志工具，并用原 CH1 的 `SCLK_0` 探头复测。验收数据为一行 `H6_CAL` 日志和一份新 CSV。SCK 长脉冲应在 121.6–134.4 µs，低等待应大于 50 µs，后面应有 32 个短时钟。两颗芯片的有效低字节都在 0x7C–0x84 才算校频通过。具体操作见 [日志与波形验收](2026-11-24-Lina-H6校频诊断与USB日志.md)。

本轮只核对工作区和测试包。下一步先做 Windows 重建。
