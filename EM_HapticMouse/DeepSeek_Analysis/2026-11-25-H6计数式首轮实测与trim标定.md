## 2. 与上一版（DelayUs）对比

| 实现 | 高脉冲均值 | 极差 |
| --- | ---: | ---: |
| `CT16B1_DelayUs`（trim 无效） | 128.2638 | 0.10 µs |

重复性提高约 10 倍，这是计数式的主要收益；绝对值偏大 0.686 µs 由固定开销造成，用一个常量就能搬回来。

## 3. trim 标定

模型：`实测 = 传入µs + trim/48 + 0.6862`，固定开销 0.6862 µs（含 APB 读 TC 的轮询延迟和退出路径）。

```
trim = round((128.00 - 128.6862) × 48) = round(-32.94) = -33
```

预期：`128.6862 - 33/48 = 127.9987 µs`。允许用 −32 或 −34 微调，两者分别落在 128.019 / 127.978。

同一个 trim 对其它脉宽按线性模型成立：

| 用途 | 传入 | counts（trim=−33） | 预期实测 |
| --- | ---: | ---: | ---: |
| td10 校频 | 128 | 6111 | 127.999 |
| td6 读写 | 39 | 1839 | 38.999 |
| td1 采样 | 5 | 207 | 4.999 |

所以只要把 `H6_PULSE_TRIM_COUNTS` 改成 **−33**，三类脉冲同时到位。

## 4. 由脉冲间距推断的尝试结果

间隔 217.7 µs = 没有 20 ms 后延（该次 `passed=0`）；20.3 ms = 通过。

本次只有第 1、2 次没有后延 → **仅第 1、2 次失败**，第 3 次起全部通过，第 16 次通过后退出。预期日志 `H6_CAL PASS n=16 …`。

对比上一版（第 1、2、7 次失败）：这次第 7 次失败**没有复现**。结合前一版，前两次失败在两次冷启动中都出现，像是上电后校频收敛过程；中途偶发失败暂时只见过一次，继续观察即可。

## 5. 低等待的三条延长

62.2 → 64.41（+2.2，单次中断）、66.79 / 66.86（+4.6，约两次中断或一次较长 USB 中断）。三条都发生在 `passed=1` 的事务里，说明低等待延长不影响校频判定；`td12` 只有下限（>50），无需处理。

高电平这次完全没被打断（极差 0.01 µs），说明 PRIMASK 临界区有效——这正是 td1 能落进 ±0.25 µs 窗口的前提。
