# 将远程源码交给本地 Windows Keil 编译

已打包远程服务器当前的源码为 [EM_HapticMouse-Windows-Keil-source.zip](EM_HapticMouse-Windows-Keil-source.zip)。它包含 `app/button.c` 的未提交改动、`Sample.uvproj`、工程源码和 scatter 文件。已校验压缩包完整性，并逐字节核对工程声明的全部 51 个文件。本包只提供构建输入，编译在 Windows 上执行。

1. 把 ZIP 下载到 Windows。如果现在用的是 VS Code Remote SSH，可在远程资源管理器中找到 `Codex_Analysis/EM_HapticMouse-Windows-Keil-source.zip`，右键选择 **Download…**。
2. 解压到 Windows 本地目录，打开解压后的 `EM_HapticMouse\Sample.uvproj`。用已安装的 ARMCC 5.06 update 7（build 960）重建 `Target 1`。详见 [Windows 重建步骤](2026-11-24-Windows-Keil重建步骤.md)。
3. 把 Build Output 的版本行、末尾汇总和首条报错（如有）发回。若重建成功，可把新生成的 `output\Sample.hex` 以新文件名传回服务器，我会核对对应的构建结果。
