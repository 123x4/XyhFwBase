# H6 NOP 版测试包刷新

本地 `main` 已包含 `b33b8a0` 的固件改动和 `66a197a` 的分析笔记。旧 Windows 包仍包含计数式代码，现已刷新并逐文件核对。最新 [测试包](Lina-H6-校频诊断-Windows.zip) 已启用 H6，校频调用为 `Hall_CLK_Command_SET(126U, 60U)`，原定时器延时后有 36 条 NOP。 [实现](../app/button.c#L811)

Cortex-M0 Clang 反汇编确认 36 条 NOP 全部在高电平定时器延时调用之后、GPIO 拉低调用之前，包含 PRIMASK 保存、屏蔽与恢复。H5 的预处理输出与修改前相同。当前工作区只有 Clang，Windows Keil ARMCC build 960 的完整构建、实际 NOP 位置和板上脉宽待实机确认。

请用包内 `Sample.uvproj` 重建 `Target 1`，烧录本次生成的 HEX。按 CH1 接 SCLK_0、80 MS/s、采集 1–2 s、高脉宽触发 80–200 µs，先点 Start 再断电上电，导出 16 条的 CSV 和相应的 `H6_CAL` 日志。当前 `untitled.csv` 仍是旧计数版。新波形到手后，`round((128.00 - 均值µs) × 48)` 给出应对现有 36 条 NOP 增减的数量，再按实测复核。 [当前校频调用](../app/button.c#L1002)
